# ColorBox Lab CRM 🎨🚗

Профессиональная CRM-система для управления сетью лабораторий подбора автоэмалей. Разработана для автоматизации работы директоров, менеджеров и колористов.

## 🚀 Основные возможности

*   **Многоролевая система**: Разделение прав доступа для Директоров, Менеджеров и Колористов.
*   **Управление филиалами**: Контроль работы сети лабораторий из единого центра.
*   **Учет заказов**: 
    *   Создание заказов с выбором услуг (Подбор, Экспресс-подбор и др.).
    *   Контроль статусов (В очереди, В работе, Готово, Выдано, Переделка).
    *   Фотоконтроль (загрузка фото детали, краски на весах и результата).
    *   Учет рецептуры компонентов.
*   **Финансы и аналитика**: 
    *   Расчет выручки по филиалам и сети в целом.
    *   Учет объема выданной краски.
*   **Учет рабочего времени**: Открытие и закрытие смен сотрудниками с фотофиксацией.
*   **Адаптивный интерфейс**: Полная поддержка мобильных устройств и ПК (Tailwind CSS).

## 🛠 Технологии

*   **Бэкенд**: Python, FastAPI, SQLAlchemy, Pydantic
*   **База данных**: PostgreSQL
*   **Шаблонизатор**: Jinja2, HTML5
*   **Фронтенд**: Tailwind CSS
*   **Работа с изображениями**: Pillow (сжатие и оптимизация фото)
